# PanCancer-Dependency

泛癌多组学功能依赖预测，以及透明细胞肾细胞癌（ccRCC）候选脆弱性研究。目前仅使用公开数据；患者域预测和生存关联不能单独证明患者功能依赖。预训练与患者跨域适配尚未实现，DDQN/MORL 不属于当前主线。

## 大型任务一：广覆盖 DepMap 跨癌系预测基线

开始日期：2026-09-14。

目的：解除原 TCGA 低频突变候选范围限制，检验多组学能否预测跨癌系功能依赖，为后续预训练与患者域迁移提供比较基线。

范围：使用 DepMap 24Q4 的突变、表达、拷贝数和 CRISPR 依赖数据，比较逐靶点训练均值、背景岭回归与共享多组学岭回归。外层留出完整癌系，内层调参保持癌系和患者分组隔离；预处理仅在训练折拟合，缺失标签不填补。分别评价 common-essential、其他基因及 Kidney 中明确 ccRCC 子集。

首轮正式结果（2026-09-14）：873 个模型、15,835 个靶点的 19 癌系 LOLO 完成，运行记录耗时约 369 秒；输入和输出哈希、患者分组均通过审查。多组学模型在 19/19 个癌系均优于训练均值基线。非普遍必需基因上，癌系等权平均 ΔR² 为 +0.04559，NDCG 从 0.61668 提升到 0.70086，Top-10 依赖命中率从 0.71310 提升到 0.83046；但平均 R² 仍为 -0.03758，逐靶点 Pearson 的癌系内中位数再取癌系平均仅为 0.09144。明确 ccRCC 的 12 个模型上，该分层 ΔR² 为 +0.07299、R² 为 -0.14751，命中率从 0.76667 提升到 0.85833。结果来源：`outputs/depmap_baseline_lolo_v1/metrics.csv`，运行与调参信息见同目录 `run.json`、`tuning.csv`。

结论：观察到排序增益，但尚不足以认为已准确预测个体依赖或发现 ccRCC 特异靶点。19 个癌系均选中多组学 α 上限 100000，需要扩大正则化搜索后再评价；全基因 Top-10 被普遍必需基因主导，且多组学预测 Top-10 的已观测标签覆盖率平均仅约 88.7%，不能用接近 100% 的已观测集合命中率证明个体化预测能力。下一轮先扩大 alpha 范围，再进行模态消融和患者分组的不确定性评估，暂不直接进入复杂预训练或患者域适配。

## 使用说明

在 WSL 中使用 `/home/liliang/miniconda3/envs/rl_genrisk/bin/python`。精简依赖见 `requirements.txt`；全新安装环境尚未验证。

- 数据构建入口：`scripts/build_depmap_baseline.py`。
- 基线训练入口：`scripts/run_depmap_baseline.py`，通过 `--help` 查看参数，`--dry-run` 只检查输入与分组。
- 模型计算默认 `--device cuda`，使用现有环境中的 PyTorch CUDA；不可用时明确报错，不自动退回 CPU。文件读写、注释处理和结果整理仍使用 CPU。运行记录保存实际设备与数值精度。
- 新版输入：`data/processed/depmap_baseline_24q4_v1/`，包含 873 个癌症模型和 15,835 个四模态共有基因，明确 ccRCC 12 个模型。来源、筛选规则和校验和见该目录的 `audit.json`。
- 新版入口读取 NPZ；历史 `run_depmap_lolo_validation.py` 读取旧 TSV，二者输入不兼容。
- 正式训练由用户手动启动。输出目录已存在时拒绝覆盖。训练入口用于评价，不保存可部署的最终模型。
- 主要结果为 `metrics.csv`，必要明细与运行信息保存在同目录的压缩表、`tuning.csv`、`splits.csv` 和 `run.json`。
- 输入数据和运行输出不纳入 Git；代码和本 README 纳入版本保存。

## 数据与结论边界

- 路径清单见 `configs/shared_data_paths.json`，仅供参考，不会自动加载；需要时通过命令行显式指定。
- 旧项目共享数据保持只读，修改处理方式时另建版本，不删除原始数据。
- `results/historical/` 是旧项目结果快照，不代表在本项目重新运行；`docs/protocols/` 为历史协议，以当前研究定位为准。迁移来源记录见 `docs/migration_manifest.md`。
- TCGA 锁定 Test 不参与训练、无监督适配、参数或模型选择。
- 历史 ccRCC 结果已参与探索，不能重新标为独立确认集；TLN1 强制锚定结果不等于独立发现。
- 四模态交集存在可用性选择偏差，不能称为全基因组无偏覆盖；common-essential 注释来自整个发布版，不能称为训练折内估计。
- 细胞系跨癌系验证不能替代患者域或独立平台验证。ccRCC 子集表现不能单独证明 ccRCC 特异性或正常组织安全性。
