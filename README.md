# PanCancer-Dependency

泛癌多组学功能依赖预测，以及透明细胞肾细胞癌（ccRCC）候选脆弱性研究。目前仅使用公开数据；患者域预测和生存关联不能单独证明患者功能依赖。预训练与患者跨域适配尚未实现，DDQN/MORL 不属于当前主线。

## 大型任务一：广覆盖 DepMap 跨癌系预测基线

开始日期：2026-09-14。

目的：解除原 TCGA 低频突变候选范围限制，检验多组学能否预测跨癌系功能依赖，为后续预训练与患者域迁移提供比较基线。

范围：使用 DepMap 24Q4 的突变、表达、拷贝数和 CRISPR 依赖数据，比较逐靶点训练均值、背景岭回归与共享多组学岭回归。外层留出完整癌系，内层调参保持癌系和患者分组隔离；预处理仅在训练折拟合，缺失标签不填补。分别评价 common-essential、其他基因及 Kidney 中明确 ccRCC 子集。

首轮正式结果（2026-09-14）：873 个模型、15,835 个靶点的 19 癌系 LOLO 完成，运行记录耗时约 369 秒；输入和输出哈希、患者分组均通过审查。多组学模型在 19/19 个癌系均优于训练均值基线。非普遍必需基因上，癌系等权平均 ΔR² 为 +0.04559，NDCG 从 0.61668 提升到 0.70086，Top-10 依赖命中率从 0.71310 提升到 0.83046；但平均 R² 仍为 -0.03758，逐靶点 Pearson 的癌系内中位数再取癌系平均仅为 0.09144。明确 ccRCC 的 12 个模型上，该分层 ΔR² 为 +0.07299、R² 为 -0.14751，命中率从 0.76667 提升到 0.85833。结果来源：`outputs/depmap_baseline_lolo_v1/metrics.csv`，运行与调参信息见同目录 `run.json`、`tuning.csv`。

正则化验证与排序-α 诊断（2026-09-14）：把 α 网格向外扩展 1000 倍至 1e8 后（`outputs/depmap_baseline_lolo_v2`），19/19 癌系的多组学 SSE 最小 α 均落在 1e5 这一内点，曲线在 1e5 触底后持续上升、到 1e8 仍未走平，说明首轮的上限选择不是边界假象；背景模型拐点仍在 1e3~1e4（17 个癌系 1e4、2 个 1e3），不受扩展影响。v2 外层全部指标与 v1 逐位一致（最大偏差 8.9e-15），故首轮数字无需修正。另对外层全部 α 逐个打分（`--alpha-scan`，见 `outputs/depmap_baseline_lolo_v3/alpha_scan.csv`）：非普遍必需分层的排序峰值在 1e4（NDCG 0.7023、命中率 0.8435），SSE 最优在 1e5（0.7009、0.8305），仅差一格，且逐癌系方向不一致（NDCG 仅 11/19、命中率 13/19 支持 1e4），差异在噪声量级内。但 α 超过 1e5 后排序单调坍缩到 1e8 的 0.6190/0.7163，与背景模型基线（0.6167/0.7131）重合，说明细胞系特异成分对排序的贡献约 +0.08 NDCG，且在 α≤1e5 的三个数量级内稳定。ccRCC 子集排序峰值同样在 1e4（NDCG 0.7773、命中率 0.9333；1e5 为 0.7325/0.8583），但 12 个模型下该差异不足一个模型量级，仅作提示、不作结论。

模态消融（2026-09-14）：把特征拆成注释基线（lineage + 5 个 driver 指示）、三个模态的逐模型均值与三个基因级模态矩阵，用分块核相加得到 8 个配置（`--ablation`，`outputs/depmap_ablation_v1`，运行 17.6 分钟）。重构后基线两方法的指标与 v3 逐位一致（最大偏差 3.2e-14，选中 α 完全相同），消融结果可用。非普遍必需分层（癌系等权）：仅表达 ΔR² +0.0502、NDCG 0.6967、命中率 0.8205，与多组学 full（+0.0456、0.7009、0.8305）在噪声内等价，逐癌系与 full 的 NDCG 差均值仅 -0.0042（5/19 反而更优）；去表达则坍缩到 0.6418/0.7512，0/19 癌系不受损。仅拷贝数 ΔR² +0.0124、NDCG 0.6436，逐癌系 19/19 低于仅表达；去拷贝数后几乎不掉（NDCG 0.6945）。仅突变 ΔR² +0.0003、NDCG 0.6169，与均值基线（0.6167）的逐癌系差均值仅 +0.00017，去突变后 NDCG 反而略升至 0.7022。ccRCC 子集（12 模型）同向且更极端：仅表达 0.7446/0.8833 优于 full 的 0.7325/0.8583。三个模态保留的可变特征数接近（表达 15,832、拷贝数 15,833、突变 12,884），故模态间差异不能归因于维度。

患者聚类不确定性与拷贝数对照（2026-09-14）：在固定癌系内按患者配对 bootstrap 20,000 次，仅表达基础上加入拷贝数的非普遍必需基因 NDCG 增量为 +0.00552（95% CI +0.00236 至 +0.00872）；癌系层级敏感性区间为 +0.00086 至 +0.01014。随后保持样本数、患者组和拷贝数协方差结构，在每个训练/验证分区内做 20 组癌系内行置换；真实拷贝数相对置换空分布的 NDCG 增量为 +0.01046（患者 bootstrap 95% CI +0.00760 至 +0.01333），19 个癌系中 17 个方向为正。连续 R² 反而变差，ccRCC 12 模型的真实拷贝数相对置换增量为 -0.00231（95% CI -0.01594 至 +0.01138）。因此拷贝数提供小幅泛癌排序信息，不能称为完全冗余，也没有显示 ccRCC 优势。突变矩阵在当前线性核模型中没有显示可复现的额外增益，但所有配置均保留 5 个驱动突变指示，不能表述为“突变生物学贡献为零”。结果见 `outputs/depmap_ablation_bootstrap_v1/` 和 `outputs/depmap_cn_control_v1/`。

纯 Sanger 外部功能验证（2026-09-15）：从 Project Score Release 1 在预测前冻结 3 个未进入当前 873 模型队列的肾癌筛选，其中明确 ccRCC 2 个；所有已知患者均与训练队列隔离。769-P 使用 Broad 直接表达，LB1047-RCC 与 RCC-FG2 使用由 107 个非 Kidney 配对模型拟合的 Sanger FPKM 至 Broad TPM 逐基因均值映射；映射选择只使用表达重建，不使用目标 CRISPR 标签。三个模型的 Top-10 NDCG、二元依赖命中和真实 Top-10 重叠均相对训练基因均值改善，但全基因 Spearman 增量分别仅 +0.00239、-0.00597、+0.00066；三者预测 Top-10 共同包含 7 个基因，显示排序仍以跨模型共享依赖为主。

为判断肾癌结果是否特殊，另在预测前冻结 66 个未入训练、患者不重叠且具有 Broad 表达的纯 Sanger 泛癌模型，按 15 个完整癌系分别留出。直接表达相对训练基因均值的 NDCG 增量平均 +0.06943（66 模型中 57 个为正；模型 bootstrap 95% CI +0.04986 至 +0.08975；癌系等权区间 +0.05270 至 +0.10687），命中率平均增加 +0.09394；Spearman 增量仅 +0.00042（95% CI -0.00127 至 +0.00205）。17 个双表达模型中，映射表达相对均值的 NDCG 增量为 +0.06762（95% CI +0.03792 至 +0.09766），但映射相对 Broad 直接表达为 -0.00386（95% CI -0.02557 至 +0.02179），没有证明映射优于同模型直接表达。769-P 的 NDCG 增量仅位于直接表达泛癌分布的 36.9% 百分位；RCC-FG2 在 17 个映射对照中位于 100% 百分位，但这是已知结果后的描述性比较，经验检验最小分辨率约为 1/18，且另一明确 ccRCC 模型并不异常，不能据此建立 ccRCC 特异性。结果见 `outputs/sanger_phase_a_769p_v1/`、`outputs/sanger_phase_b_v1/`、`outputs/sanger_external_controls_v1/` 和 `outputs/sanger_external_controls_analysis_v1/`。

选择性依赖残差验证（2026-09-15）：将评价目标改为相对每个外层训练折逐基因均值的依赖残差，固定表达模型 α=1e5，不根据新指标调参；主分析排除 release-wide common-essential，并以训练折内逐基因残差第 10 百分位作为不使用当前模型表达的选择性先验。19 个完整癌系留出共评价 805 个模型（基础训练数据仍为 873 个模型），癌系等权 NDCG 从 0.2248 提升至 0.4178，配对增量 +0.1930；选择性命中率增量 +0.1642、Spearman 增量 +0.1760、regret 降低 0.3978。NDCG 增益在 684/805 个模型、662/780 个患者和 19/19 个癌系中为正；患者等权 bootstrap 95% CI 为 +0.1792 至 +0.2060，癌系等权为 +0.1599 至 +0.2231。12 个明确 ccRCC 模型的增量为 +0.3450，但相对其他 Kidney 模型的额外增量仅 +0.0834，95% CI 为 -0.0558 至 +0.2239，未证明 ccRCC 特异优势。该目标与先验是在先前绝对依赖分析后提出，结果属于探索性证据；common-essential 注释也不是训练折内估计。结果见 `outputs/selective_dependency_lolo_v1/` 和 `outputs/selective_dependency_analysis_v1/`。

结论：α 边界问题已解决，表达驱动的绝对依赖 Top-10 排序增益能够在纯 Sanger 标签的未训练模型上复现，内部整癌系留出也支持表达预测选择性依赖残差；拷贝数只有小幅泛癌排序贡献，突变矩阵未显示额外贡献。尚未证明准确的跨平台连续残差、ccRCC 特异依赖或患者功能依赖。下一步应使用非 Kidney 配对筛选建立 Broad Chronos 与 Sanger BAGEL 的训练内标准化，再评价冻结的纯 Sanger 泛癌队列；两种标签未经校准不能直接相减或据此进入患者域适配。

## 使用说明

在 WSL 中使用 `/home/liliang/miniconda3/envs/rl_genrisk/bin/python`。精简依赖见 `requirements.txt`；全新安装环境尚未验证。

- 数据构建入口：`scripts/build_depmap_baseline.py`。
- 基线训练入口：`scripts/run_depmap_baseline.py`，通过 `--help` 查看参数，`--dry-run` 只检查输入与分组；`--alpha-scan` 额外对外层全部 α 打分并输出排序-α 诊断表，`--ablation` 增加模态消融配置（留一与单模态，共用分块核矩阵）。两者默认关闭、不改变 `metrics.csv`。消融配置中所有方法均保留 lineage 与 5 个 driver 指示作为共享注释基线，`drop_X` 同时去掉 X 的基因级矩阵与逐模型均值；因此"仅突变"应读作"注释基线 + 突变模态"，5 个 driver 本身即突变信息。
- 选择性残差入口：`scripts/run_selective_dependency.py`；GPU 聚类不确定性分析为 `scripts/analyze_selective_dependency.py`。前者固定 α=1e5 和训练折内第 10 百分位先验，拒绝覆盖已有输出；后者以患者和癌系分别作为 bootstrap 单位。
- 模型计算默认 `--device cuda`，使用现有环境中的 PyTorch CUDA；不可用时明确报错，不自动退回 CPU。文件读写、注释处理和结果整理仍使用 CPU。运行记录保存实际设备与数值精度。
- 新版输入：`data/processed/depmap_baseline_24q4_v1/`，包含 873 个癌症模型和 15,835 个四模态共有基因，明确 ccRCC 12 个模型。来源、筛选规则和校验和见该目录的 `audit.json`。
- 新版入口读取 NPZ；历史 `run_depmap_lolo_validation.py` 读取旧 TSV，二者输入不兼容。
- 正式训练由用户手动启动。输出目录已存在时拒绝覆盖。训练入口用于评价，不保存可部署的最终模型。
- 主要结果为 `metrics.csv`，必要明细与运行信息保存在同目录的压缩表、`tuning.csv`、`splits.csv` 和 `run.json`；启用 `--alpha-scan` 时另有 `alpha_scan.csv`。`run.json` 的 `feature_configs` 逐方法记录该配置包含哪些特征块，是消融结果可复现的必要依据。
- 输入数据和运行输出不纳入 Git；代码和本 README 纳入版本保存。

## 数据与结论边界

- 路径清单见 `configs/shared_data_paths.json`，仅供参考，不会自动加载；需要时通过命令行显式指定。
- 旧项目共享数据保持只读，修改处理方式时另建版本，不删除原始数据。
- `results/historical/` 是旧项目结果快照，不代表在本项目重新运行；`docs/protocols/` 为历史协议，以当前研究定位为准。迁移来源记录见 `docs/migration_manifest.md`。
- TCGA 锁定 Test 不参与训练、无监督适配、参数或模型选择。
- 历史 ccRCC 结果已参与探索，不能重新标为独立确认集；TLN1 强制锚定结果不等于独立发现。
- 四模态交集存在可用性选择偏差，不能称为全基因组无偏覆盖；common-essential 注释来自整个发布版，不能称为训练折内估计。
- 模态消融未包含维度匹配的随机特征安慰剂，故模态排序仍可能混入维度效应；但三个模态保留的可变特征数接近（表达 15,832、拷贝数 15,833、突变 12,884），该威胁被实质削弱。消融结论限于线性核岭回归这一类模型，不能推广为"该模态在生物学上无用"。
- 细胞系跨癌系验证不能替代患者域或独立平台验证。ccRCC 子集表现不能单独证明 ccRCC 特异性或正常组织安全性。

3. 明确区分事实、推测和主观观点。
4. 涉及数字、人物和结论时核实来源；无法核实则明确说明。
5. 不同意时直接指出，给出依据、风险和替代解释。
6. 主动指出被忽略的变量、成本和偏差。
7. 自行清理不重要的临时脚本与冗余结果，保留主要结论、重要负结果及必要复现与审计材料。
8. README 只在大型任务开始和最终完成时记录目的、范围及结果；不按每次对话或子任务追加中间过程，不另建 Markdown 过程报告。长期规则和必要使用说明发生变化时可更新相应内容。
9. 每次任务结束，需要用户手动执行的操作必须在回复中直接给出可复制命令，不能只让用户查看 README；明确指出下一步要做什么。没有手动操作时不编造操作要求。
10. 在初始基线、重要修改或实验完成、较大重构或清理前等合适时机提醒用户用 Git 保存工程。
11. 后续运行任务使用简洁中文终端输出，清楚显示当前阶段、进度、耗时、关键评价结果及保存位置；明确区分程序检查和正式实验。
12. 后续模型训练及可加速的数值计算优先并默认使用 GPU；不静默退回 CPU。文件读写等不适合 GPU 的操作仍由 CPU 处理。
