# PanCancer-Dependency

## 项目概览

本项目研究一个问题：**能否利用大量癌细胞系中已经测量的基因表达和基因依赖数据，学习一套可迁移的方法，再从透明细胞肾细胞癌（clear cell renal cell carcinoma，ccRCC）患者的肿瘤表达数据中筛选值得实验验证的依赖候选？**

这里的“基因依赖”是指癌细胞在某个基因被敲除或抑制后，生长或存活受到影响。“功能依赖”需要基因扰动实验直接证明。患者肿瘤的 RNA 表达只能帮助提出候选，不能代替功能实验。

项目只使用公开数据。主线已经从泛癌细胞系训练推进到跨平台验证、患者表达迁移、候选冻结和多层证据审查。当前形成的是一套**候选优先级流程和冻结的实验候选集**，尚未证明患者特异的 ccRCC 功能依赖，也没有建立药物疗效、安全性或正常肾治疗窗。DDQN 和多目标强化学习不属于当前研究主线。

## 研究目的

项目依次回答五个问题：

1. 泛癌细胞系中的分子信息能否预测一个细胞系依赖哪些基因？
2. 模型学到的是普遍必需基因，还是具有细胞系差异的选择性依赖？
3. 这种信号能否从 Broad/DepMap CRISPR 数据迁移到独立的 Sanger CRISPR 和 DRIVE RNAi 平台？
4. 在没有患者功能标签的条件下，模型给出的 ccRCC 患者候选能否在独立患者分组中保持稳定？
5. 冻结候选是否同时具备独立功能证据、ccRCC 特异性和可接受的正常肾风险？

预期目标不是直接从计算结果宣布治疗靶点，而是建立一条可审计的筛选流程，缩小后续基因扰动实验需要验证的范围，并清楚标明每个结论的证据等级。

## 整体流程

```text
DepMap 泛癌 CRISPR 与多组学数据
              │
              ▼
完整癌系留出训练与模态消融
              │
              ▼
去除 common-essential 后预测选择性依赖
              │
              ▼
Sanger CRISPR 与 DRIVE RNAi 跨平台复现
              │
              ▼
TCGA-KIRC 患者表达跨域映射
              │
              ▼
Train 发现 → Validation 稳定性 → 锁定 Test 一次性确认
              │
              ▼
文献、正常肾表达、类器官风险与可成药性审查
              │
              ▼
冻结 20 个候选及其证据边界
```

训练和外部验证始终按患者或完整癌系隔离，避免同一患者来源模型同时进入训练与评价。患者端没有基因敲除后的真实结果，因此只评价排序稳定性和输入敏感性，不把它们称为预测准确率。

## 数据和评价方法

- **DepMap 24Q4**：873 个癌细胞系、15,835 个共有基因，包含表达、拷贝数、突变和 CRISPR 依赖；其中明确注释的 ccRCC 模型为 12 个。
- **Sanger Project Score**：用于检验 Broad/DepMap 上训练的规律能否迁移到另一套 CRISPR 实验平台。
- **DRIVE-only DEMETER2**：使用独立 RNAi 扰动技术复查候选方向，避免只依赖 CRISPR。
- **TCGA-KIRC**：156 个 Train、53 个 Validation、51 个锁定 Test 患者；Test 在协议和代码提交后只正式访问一次。
- **HPA、GTEx 和正常肾类器官文献**：定位正常肾脏和肾单位细胞中的表达或功能风险。
- **Open Targets 与同行评议文献**：核查可成药性、直接 loss-of-function 支持和反向证据。

主要排序指标为 NDCG，它衡量真正强依赖基因是否被排在候选列表前部；数值越高，头部排序越好。Spearman 衡量两份完整排序或候选频率的一致程度。Top-10/Top-100 重叠衡量两种设置给出的头部候选有多少相同。所有这些指标都必须结合评价数据是否具有功能真值来解释。

## 阶段成果

### 阶段一：建立泛癌功能依赖基线

在 19 个癌系上进行完整癌系留出：每次用其他癌系训练，再预测完全未参与训练的癌系。多组学模型在 19/19 个癌系上优于训练基因均值。非 common-essential 基因的癌系等权 NDCG 从 0.6167 提升到 0.7009，Top-10 依赖命中率从 0.7131 提升到 0.8305。

模态消融显示，表达提供了绝大多数可复现的预测信息：仅表达模型的 NDCG 为 0.6967，与完整多组学模型的 0.7009 接近；去掉表达后降至 0.6418。拷贝数提供小幅但可检测的泛癌排序增益，突变矩阵在当前线性模型中没有显示额外稳定增益。这个结论只适用于本项目的模型和输入，不能解释为突变或拷贝数在癌症生物学中不重要。

相关结果位于 `outputs/depmap_baseline_lolo_v1/`、`outputs/depmap_baseline_lolo_v2/`、`outputs/depmap_baseline_lolo_v3/`、`outputs/depmap_ablation_v1/`、`outputs/depmap_ablation_bootstrap_v1/` 和 `outputs/depmap_cn_control_v1/`。

### 阶段二：从普遍依赖转向选择性依赖

早期外部验证发现，模型能提高 Top-10 排序，但全基因相关性几乎不变，说明结果容易被所有细胞共同需要的基因主导。因此后续评价排除了 release-wide common-essential，并预测相对训练基因均值的依赖残差。

在 805 个可评价模型、19 个完整癌系留出中，表达残差模型相对训练选择性先验的癌系等权 NDCG 从 0.2248 提升到 0.4178，增量为 +0.1930；患者等权 bootstrap 95% 区间为 +0.1792 至 +0.2060，19/19 个癌系方向为正。这证明表达对“哪些模型比平均水平更依赖某个基因”的排序有稳定信息。

12 个 ccRCC 模型的增量更大，但相对其他 Kidney 模型的额外增益区间跨 0，因此没有证明该方法对 ccRCC 特别有效。结果位于 `outputs/selective_dependency_lolo_v1/` 和 `outputs/selective_dependency_analysis_v1/`。

### 阶段三：跨实验平台验证

在预测前冻结的 66 个纯 Sanger 泛癌模型上，Broad 直接表达模型相对训练选择性先验的 ΔNDCG 为 +0.1065，95% 区间为 +0.0776 至 +0.1360，54/66 个模型和 15/15 个癌系方向为正。这说明表达驱动的选择性排序能够跨 CRISPR 平台复现。

但绝对 NDCG 只有 0.1670，真实 Top-10 重叠只有 0.0303，说明外部平台上的具体基因名单仍不够准确。需要表达映射的 17 个模型中，ΔNDCG 为 +0.0576，区间 -0.0099 至 +0.1285，未达到稳定复现。单个肾癌模型表现较好也不能证明 ccRCC 特异性。

结果位于 `outputs/sanger_phase_a_769p_v1/`、`outputs/sanger_phase_b_v1/`、`outputs/sanger_external_controls_v1/`、`outputs/sanger_external_controls_analysis_v1/` 和 `outputs/sanger_selective_dependency_v1/`。

### 阶段四：患者表达迁移和候选冻结

模型使用 850 个非 Kidney DepMap 模型训练，再把 TCGA-KIRC 患者表达映射到细胞系表达空间。患者端没有依赖标签，因此这一阶段只能检验候选排序是否稳定。

Train 与 Validation 的活跃候选频率 Spearman 为 0.5645，Top-100 重叠为 0.7400。driver 中性化几乎不改变排序，但使用非 Kidney 或 Kidney 表达偏移进行映射时，Top-10 重叠只有 0.3651，说明跨域映射是主要不确定性。项目在查看外部候选证据之前冻结了 discovery rank 前 20，后续没有根据 Validation、Test、文献或正常组织结果重排。

冻结候选依次为：SEPHS2、GRB2、HNF1B、SEPSECS、CFLAR、YRDC、PAX8、EEFSEC、SLC33A1、CHMP7、YPEL5、HSD17B12、PSTK、FOXA1、UBR5、CCND1、GCN1、UXS1、FERMT2、WDR73。

结果位于 `data/processed/tcga_kirc_expression_bridge_v1/`、`outputs/tcga_patient_transfer_v1/` 和 `outputs/tcga_candidate_evidence_v2/`。

### 阶段五：锁定 Test 一次性确认

Test 协议、模型、输入映射、候选、指标和重点基因预期方向先以 Git 提交 `73f9972` 固定，随后正式访问 51 个 Test 患者一次，没有使用 Test 调参、选映射或重排候选。

Train–Test 活跃基因频率 Spearman 为 0.5450，Top-100 重叠为 0.75；Validation–Test 分别为 0.4500 和 0.70。冻结前 20 的 Validation–Test 频率 Spearman 为 0.7984，说明固定候选在未见队列中的相对出现频率较稳定。

映射不确定性同样在 Test 中出现：两种预设映射的患者 Top-10 平均重叠为 0.3608，95% 区间为 0.3157 至 0.4098。14 个配对肿瘤—邻近正常样本中，PAX8、FERMT2 和 CCND1 的预设表达方向复现且区间不跨 0；HNF1B 中位数方向一致，但区间跨 0，不能称为确认。该 Test 没有功能标签，只确认未见患者中的稳定性和表达方向。

协议见 `configs/tcga_locked_test_protocol_20260916.json`，结果位于 `outputs/tcga_locked_test_v1/`，版本化快照位于 `results/historical/tcga_locked_test_v1/`。

### 阶段六：候选的独立功能和正常肾风险审查

DRIVE-only RNAi 数据包含 397 个模型，其中映射出 8 个 ccRCC。冻结候选中有 10 个被该文库覆盖。PAX8、HNF1B 和 FERMT2 的 ccRCC 依赖残差区间完全低于 0，支持 Kidney/ccRCC 谱系依赖方向；只有 PAX8 相对其他 Kidney 模型的区间也完全低于 0。由于 DRIVE 与当前 CRISPR 基线存在部分模型重叠，这属于独立扰动平台复现，不是完全独立患者队列验证。

正常组织证据同时暴露出风险。GTEx v11 中 PAX8 的 Kidney Cortex/Medulla 中位表达为 179.12/351.62 TPM，HNF1B 为 51.63/97.90 TPM，FERMT2 的肾脏最高中位表达为 33.46 TPM。HPA 肾脏单细胞数据也显示三者位于多种肾单位细胞。公开正常肾类器官扰动文献进一步显示，PAX8 或 HNF1B 被抑制会影响肾类器官形成、分化或细胞周转。这些证据提示风险，但不能直接换算成人体药物毒性。

同行评议的直接功能文献支持集中在 PAX8 和 CCND1；YPEL5 存在反向结果，即在 786-O 细胞中敲低后增殖、迁移和侵袭增强。CCND1 具有肿瘤高表达和临床阶段 tractability 记录，但 DRIVE 的绝对依赖区间跨 0。

结果位于 `outputs/candidate_external_validation_v1/`、`outputs/candidate_external_adjudication_v1/`、`outputs/candidate_orthogonal_validation_v1/` 和 `outputs/candidate_celltype_window_v1/`。

### 阶段七：患者来源功能数据审计

项目检查了公开的 Sanger 肿瘤类器官 CRISPR、Broad NextGen Dependency Map、ccRCC 类器官、PDX 和相关筛选研究。预先要求数据必须同时满足：人患者来源 ccRCC、候选基因 loss-of-function、细胞生长或肿瘤终点，并独立于现有传统细胞系。

在冻结审计范围内，符合条件的公开资源为 0。现有 ccRCC 类器官研究主要提供药物或 CAR-T 反应，相关基因筛选大多仍在 786-O、Caki-1 或其他传统细胞系完成。这个结果表示目前缺少可用数据，不表示候选一定无效。

结果位于 `outputs/ccrcc_primary_functional_audit_v1/`，版本化快照位于 `results/historical/ccrcc_primary_functional_audit_v1/`。

### 阶段八：证据整合、图件和复现封装

项目把 20 个冻结候选的计算排序、CRISPR、RNAi、直接文献、TCGA 表达、HPA/GTEx 正常肾暴露、正常肾类器官风险和可成药性整理成不使用综合分数的证据矩阵。历史 v1 生成在锁定 Test 之前并保留为审计版本；当前 v2 已加入 Test 候选频率、映射敏感性和四个预设基因的表达方向，但没有改变候选顺序、功能证据等级或结论上限。

论文图件 v2 包含 4 张 300 dpi PNG 和 4 份矢量 PDF，分别展示公平 baseline、内部与外部复现、Locked Test 稳定性、证据递减、候选证据矩阵和功能—正常肾暴露关系。发布校验脚本已核对 6 个版本化结果目录中的 38 个文件哈希、冻结候选、结论上限、两份冻结协议、环境版本和图像文件签名。外部输入校验覆盖 9 个主流程文件，共 1.33 GiB。关键脚本已移除个人机器绝对路径，并固定公开数据与软件版本。

相关产物位于 `outputs/final_evidence_synthesis_v2/`、`outputs/final_figures_v2/`、`results/historical/` 和 `configs/publication_release_manifest.json`。v1 的证据表与运行记录仍保留用于追踪 Test 解锁前后的变化；旧版图件已删除，图件以 v2 为准。

### 阶段九：强 baseline、公平比较与既有工作定位

比较协议在运行前以 Git 提交 `170d62e` 固定。19 个 DepMap 完整癌系使用相同训练/留出模型、相同患者隔离、相同非 common-essential 基因、相同选择性残差目标和相同 NDCG@10 主指标。非平凡 baseline 的参数只在对应外层训练数据内按完整癌系分组选择，不读取 Sanger 或 TCGA Test 标签。比较方法包括训练选择性先验、仅注释岭回归、表达近邻、低秩表达 PCR-ridge、历史冻结表达核岭和训练内调参表达核岭。

癌系等权 NDCG 分别为 0.2248、0.1713、0.3350、0.4411、0.4177 和 0.4401。历史冻结核岭仍显著优于选择性先验，患者等权 ΔNDCG 为 +0.1926（95%区间 +0.1792 至 +0.2059），也优于表达近邻 +0.0771（+0.0684 至 +0.0857）；但它稳定低于 PCR-ridge，冻结核岭减 PCR 的差为 -0.0233（-0.0288 至 -0.0180）。因此原结论“表达包含可迁移的选择性依赖信息”成立，但“历史固定核岭是最强实现”不成立。训练内调参核岭达到 0.4401，说明主要差异来自正则化和低秩控制，而不是需要更复杂的深度模型。

同一批 DepMap 所选参数随后原样用于冻结 Sanger 外部队列。Pleura 和 Prostate 各只有一个外部模型，但在 DepMap 中没有达到20模型的合法调参癌系，因此没有借用其他癌系参数；公平比较覆盖 64/66 个模型、13个癌系。癌系等权 NDCG 中，选择性先验为 0.0566、表达近邻 0.1820、PCR-ridge 0.2287、冻结核岭 0.1982、调参核岭 0.2367。冻结核岭减 PCR 的患者等权差为 -0.0355（95%区间 -0.0577 至 -0.0148），确认 PCR 的相对优势能够跨到 Sanger；但所有外部绝对指标仍不足以直接给出患者治疗靶点。

与 Shi 等人在 2024 年 Nature Cancer 发表的 TCGA-DEPMAP 工作相比，两者都发现表达是依赖预测的主要信息，并把细胞系模型迁移到 TCGA。该工作使用较早 DepMap 的绝对 CERES 依赖、逐靶点 elastic net、筛选后的 1,966 个可预测模型，以及 quantile normalization 和 contrastive PCA，覆盖泛癌 TCGA、PDX、GTEx、药物反应和合成致死实验。本项目使用 DepMap 24Q4，重点预测 common-essential 校正后的选择性残差，采用更严格的完整癌系留出、Sanger CRISPR 和 DRIVE RNAi 复现、ccRCC 冻结候选、一次性患者 Test 与正常肾风险审计。DeepDEP 则通过 TCGA 无标签预训练和深度网络完成泛癌迁移。由于三者的数据版本、靶点集合、目标定义和划分不同，本项目没有把论文中已发表的指标伪装成同数据胜负比较，也不宣称全面优于 TCGA-DEPMAP 或 DeepDEP。差异表位于 `configs/prior_work_comparison_20260916.csv`。

结果位于 `outputs/selective_dependency_benchmark_v1/`、`outputs/sanger_baseline_benchmark_v1/`、`outputs/final_evidence_synthesis_v2/` 和 `outputs/final_figures_v2/`，冻结协议见 `configs/dependency_benchmark_protocol_20260916.json`。

### 阶段十：同数据高级模型比较（内部与外部主比较完成）

本阶段检验：增加算法复杂度能否提高选择性依赖排序。使用相同 DepMap 24Q4 输入和整癌系留出，对 PCR-ridge、逐靶点 Elastic Net、多任务低秩岭回归和 Exp-DeepDEP 同数据适配版进行比较。873 个输入模型中，805 个模型进入 19 个外层留出癌系，涉及 780 位患者；共同靶点为 1,204 个，主评价限定在其中 911 个非 common-essential 基因。所有拟合与 bootstrap 使用 GPU。该评价不是此前全基因空间的直接续分，不能把这里的 0.4585 与阶段九的 0.4411 相减解释为改进。

| 方法 | 内部癌系等权 NDCG@10 | 相对 PCR 的内部差值及 95% 区间 | Sanger 癌系等权 NDCG@10 |
|---|---:|---:|---:|
| PCR-ridge | 0.4585 | 参照 | 0.3351 |
| 多任务低秩岭回归 | 0.4594 | +0.0009 [−0.0043, +0.0060] | 0.3270 |
| Elastic Net（共享 α） | 0.4428 | −0.0157 [−0.0265, −0.0047] | 0.3029 |
| Elastic Net（逐靶点 α，次要比较） | 0.4131 | −0.0454 [−0.0590, −0.0324] | 未外部重拟合 |
| Exp-DeepDEP 同数据适配版 | 0.2600 | −0.1985 [−0.2266, −0.1717] | 0.1665 |
| 训练选择性先验 | 0.2363 | −0.2222 [−0.2501, −0.1916] | 0.0725 |

外部主比较沿用 DepMap 所选超参数和 DeepDEP 三个种子的训练轮数，不按 Sanger 标签调参；覆盖 64 个模型、13 个癌系、871 个共同评价基因，跨平台校准只使用非目标癌系的配对模型。低秩模型减 PCR 的外部差值为 −0.0082，癌系 bootstrap 95% 区间 [−0.0336, +0.0159]；Elastic Net 为 −0.0322 [−0.0671, +0.0049]。这些外部差异区间包含零，不能宣称 PCR 显著胜过所有方法。低秩模型内部 Spearman 确有 +0.0114 的增益（95% 区间 [+0.0056, +0.0188]），但不能替代预先指定的 Top-10 排序主指标。

**本阶段结论：尚无复杂模型满足可靠超过 PCR-ridge 的主指标要求，继续保留 PCR-ridge 作为主要比较基线。** 这不证明深度模型普遍无效，也不改变历史冻结候选的生成模型。Sanger 是此前已检查过的队列，属于既有外部数据上的方法比较，不是新获得的未触碰测试集。

复现有以下实质边界：DeepDEP 的 6,016 个表达位置只有 4,678 个来自当前处理后的共同特征矩阵，1,338 个用官方参考均值填补；原始表达数据能提供更多特征，此限制可能影响深度模型。预训练使用 8,829 个非 KIRC 肿瘤；依赖目标、数据版本、完整癌系划分和结构化批次均与论文不同，因此必须称为“同数据适配版”，不能作为原版 DeepDEP 的严格复现胜负。经典模型按内层 NDCG 选参，DeepDEP 按首个内层折的 MSE 选训练轮数，搜索预算并不完全相同。

审计还确认了两项需要公开的限制：开发期间检查过 Biliary 留出表现，并在首次完整运行未通过收敛检查后修订优化器停止设置，因此不能称为全程未看结果的前瞻预注册；Elastic Net 的 456 条路径均达到系数变化停止阈值，但这不是逐靶点最优性证明。预训练读取器曾解析包含 KIRC 的整行源数据再排除相应列，KIRC 未进入训练或统计；历史记录“完全未读取 KIRC 数值”的字面表述不准确，已在补充审计中更正，未重新进行患者 Test 评价。

### Elastic Net 数值审计：求解精度是否解释性能差距

已在 GPU 上复算全部 19 个真实外层训练折，固定各折历史所选 α=0.1，不重新调参；历史逐模型指标最大复算误差为 2.22×10⁻¹⁶。随后在相同浮点输入上使用双精度求解，并逐靶点检查最优性残差和目标函数误差上界。22,876 个“癌系×靶点”组合中，15,105 个历史解未达到此次更严格的证书标准；精化后全部通过，最大 KKT 残差为 9.95×10⁻⁷，最大相对目标函数误差上界为 1.22×10⁻⁹。未达到新证书不等于旧结果全部无效，但也不能把原来的系数变化停止条件称为最优性保证。

精化后的癌系等权 NDCG 为 **0.4405**，历史 Elastic Net 为 **0.4428**，PCR-ridge 为 **0.4585**。精化减历史的差为 −0.00236，95% 癌系 bootstrap 区间 [−0.00451, −0.00027]；精化减 PCR 为 −0.01802 [−0.02923, −0.00690]。因此，在固定历史 α 的条件下，更充分优化没有挽回与 PCR 的差距。单个预测值最大变化约 0.303，不能把所有数值影响都描述成可忽略；平均排序结论保持一致，并不等于每个预测不变。

本次仅审计共享 α 的外层重拟合；尚未认证全部内层选参路径、逐靶点 α 版本或精化后的 Sanger 结果。尤其是 19 个癌系均选中原网格上边界 α=0.1，仍需检查更大的正则化范围。该结果支持“固定设置下，优化精度没有解释性能落后”，不能升级为“Elastic Net 模型类别不如 PCR”。协议为 `configs/elastic_net_numerical_audit_protocol_20260920.json`，入口为 `scripts/audit_elastic_net_numerics.py`，证书与敏感性结果版本化至 `results/historical/elastic_net_numerical_audit_v1/`。

### Elastic Net 上界敏感性：扩大正则化范围是否有效

已完成预先固定的 α={0.1, 0.2, 0.5, 1.0} 比较，复用 19 个外层癌系及各自 5 个训练内折，只按内层癌系等权 NDCG 选择参数。380 条内层路径和 19 次外层拟合共覆盖 480,396 次靶点拟合，全部通过全特征最优性检查；最大 KKT 残差为 1.00×10⁻⁶ 以内，最大相对目标函数误差上界为 1.78×10⁻⁹。计算使用 GPU，累计约 24.8 分钟。

19 个癌系全部仍选 α=0.1。将各外层训练任务的内层分数取平均，四个 α 的 NDCG 分别为 0.4281、0.3843、0.2676、0.1390；这些训练任务彼此重叠，此处只是描述性汇总。外层扩展网格与固定 α 的预测完全相同，癌系等权 NDCG 均为 **0.440465**，增益为零。相对 PCR-ridge 的 0.458497，差值为 −0.018031，95% 癌系 bootstrap 区间 [−0.029247, −0.006905]。本轮求解器与前次精化结果的 NDCG 相差约 0.000012，两者均通过各自数值条件；数值条件不保证排序逐项完全相同。

**结论：在测试的网格内，提高 α 上界没有挽回 Elastic Net 的性能差距。** 按预设规则，未达到再做 Sanger 拟合的条件，因此没有重复外部实验。该结果只回答上界敏感性：更小的历史 α 路径、0.1 附近更密集网格及其他 l1_ratio 仍未完整认证，不能解释成已穷尽 Elastic Net。结果属于既有外层队列上的开发分析，不是新增独立验证。

协议为 `configs/elastic_net_upper_grid_protocol_20260920.json`，运行入口为 `scripts/run_elastic_net_upper_grid.py`，数值求解为 `scripts/certified_elastic_net.py`。正式结果与证书汇总保存在 `results/historical/elastic_net_upper_grid_v1/`，完成后临时断点已自动删除。

7位作者ccRCC供者中，将肿瘤和非肿瘤细胞的CPM按RNA比例混合，再对每种场景进行供者均值映射。在共同的13,515基因排序空间内，25%、50%、75%非肿瘤RNA混合与肿瘤细胞单独场景的Top-10平均重叠分别为 **0.4857、0.3143、0.1286**；实际全部细胞汇总场景为0.2286。仅标签一致的3位肿瘤供者中，三个混合场景分别为0.40、0.20、0.10。该结果是细胞混合敏感性的探索，不是实测TCGA纯度校正或患者依赖验证；单细胞CPM与DepMap TPM尺度不等价，场景均值映射也会去掉部分组间均值差异。

### PCR 排序不稳定性来源审计（2026-10-10 完成）

按预先冻结的 `configs/pcr_instability_audit_protocol_20261010.json` 完成四项诊断：统一基因均值参照、标准化/PCA/回归的配对条件对照、Top10/20/50 边界检查，以及全部19个历史 DepMap 整癌系留出的功能关系评价。TCGA 使用原有209位 Train/Validation 患者和50次来源患者抽样，逐基因完全复现旧版 Top10 纳入次数；功能评价覆盖805个模型、780位来源患者，每癌系20次抽样。共430次来源患者抽样，每次均运行六组对照；沿用各外层历史训练内选参，不重新选模型或候选，不读取 Locked Test 表达。

统一参照的残差等于“重采样模型的残差＋重采样训练基因均值－原训练基因均值”。以下均为重采样名单与原模型名单的平均 Top10 重叠；TCGA 按患者等权，DepMap 先患者等权、再癌系等权。

| 条件对照 | TCGA Train | TCGA Validation | DepMap 19癌系 |
|---|---:|---:|---:|
| 全部重拟合，使用抽样自身基因均值（旧定义） | 0.2748 | 0.2534 | 0.6247 |
| 全部重拟合，统一原训练基因均值 | 0.2745 | 0.2539 | 0.6218 |
| 仅改变基因均值参照，原始预测固定 | 0.9079 | 0.8954 | 0.9393 |
| 标准化和 PCA 固定，仅重拟合回归 | 0.4179 | 0.4026 | 0.6496 |
| 标准化固定，重拟合 PCA 和回归 | 0.3076 | 0.2907 | 0.6250 |
| PCA 载荷固定，重拟合标准化和回归 | 0.3713 | 0.3531 | 0.6447 |

**基因均值参照漂移不是 TCGA 排序不稳定的主要来源。** 统一参照几乎不改变旧结果；固定标准化与 PCA 后，Validation Top10 重叠仍只有0.4026，说明回归拟合也有明显抽样波动。固定标准化的 PCA 重拟合与原子空间平均平方典型相关为0.6957，平均主角度30.70°，比较对载荷符号和子空间旋转不敏感。预测变化的四个有序条件差及全部有符号交叉项均保存，重构误差通过校验；这些对照依赖顺序且彼此相关，不能解释为可相加的因果贡献百分比。固定 PCA 的对照仅用于诊断，没有据此选择新部署模型。

扩大名单不能解决细节排序波动：统一参照下，Validation Top20/Top50 平均重叠分别为0.2800/0.3038，Train 为0.2979/0.3196。Validation 第11名减第10名残差的中位数为0.00387，第10名残差±0.01内平均有5.68个基因；但该边界间隔与 Top10 稳定性的 Spearman 仅0.0834（Train 0.1938），不足以单独判定名单可靠性。更大名单的重叠还受到名单长度的机械影响。

**稳定性在已有细胞系功能标签上有诊断价值，但没有成为已校准的患者依赖概率。** 统一参照 Top10 稳定性与原模型功能 NDCG 的全体患者 Spearman 为0.3774，平均癌系内 Spearman 为0.3128。按预设的癌系内平均秩上/下三分组，高稳定性组减低稳定性组的癌系等权 NDCG 差为0.1098；2000次癌系簇抽样的描述性95%区间为[0.0815, 0.1399]，19癌系均有有效分组。同一患者的多个模型先合并，抽样次数不当作独立样本；训练集重叠和既有开发数据复用限制该区间的确认性解释。六组对照、三种名单长度和并列秩组大小全部保留，没有按功能结果选择阈值。原模型癌系等权 NDCG 为0.4406，全重拟合统一参照的抽样平均为0.4103，本轮没有证明新预测模型优于原模型。

基因覆盖单独审计：历史基准使用所有比较方法共有的有限预测空间，本轮使用六组 PCR 对照共有、训练标签≥20且该模型有功能标签的空间。804/805个模型的原始 NDCG 与历史一致到数值精度；周围神经系统模型 ACH-002283 多纳入80个基因，NDCG 从0.3459变为0.2035。核查确认历史 expression-kNN 的选中邻居在这些基因上没有标签，导致历史多方法共同空间将其排除；本轮保留它们符合预设 PCR 审计规则。独立核 PCR 的最大预测差仅6.40×10⁻¹⁵，恢复历史有限预测掩码后 NDCG 完全复现，故该差异来自评价空间，不能宣称为模型性能变化。

完整输出在 `outputs/pcr_instability_audit_v1/` 和 `outputs/pcr_instability_synthesis_v1/`，逐次/逐癌系表留在本地；紧凑表和三组300dpi PNG/矢量PDF在 `results/historical/` 同名目录。[配对对照图](results/historical/pcr_instability_synthesis_v1/图08_PCR排序不稳定性的来源对照.png)、[功能关系图](results/historical/pcr_instability_synthesis_v1/图09_排序稳定性与功能预测表现的关系.png)、[候选边界图](results/historical/pcr_instability_synthesis_v1/图10_候选排名边界间隔与排序稳定性.png)可直接审查。发布检查通过19个快照文件、20组案例、430次抽样哈希复放、患者隔离、旧抽样一致性、汇总复算与有序交叉项重构（最大误差4.73×10⁻¹⁶）；核查记录在 `results/historical/pcr_instability_validation_v1/`。路径命名失败的初次局部输出保留在 `outputs/pcr_instability_audit_v1_initial/`，不属于正式结果。

本轮把计算候选转化为可审查的实验设计；没有取得实体模型、订购试剂或产生功能结果。实验室模型条件尚未提供，默认设计为同一供者的成人ccRCC与邻近正常近端小管类器官。患者来源肾癌及正常肾模型有[已发表培养方案](https://doi.org/10.1016/j.omtm.2024.101368)，但培养成功率、肿瘤纯度及正常组织状态仍须逐例核实。已有肾癌细胞系可先做技术可行性；不同来源正常细胞不能冒充同供者配对。公共单细胞供者不代表本项目拥有实体样本。

**固定验证面板，不重排历史名单。** 主面板为PAX8、HNF1B、FERMT2、CCND1：前两者重点检查正常肾风险，FERMT2检查肾相关依赖是否具有肿瘤差异，CCND1检查已有文献与较弱跨平台功能证据的落差。探索面板为新PCR前三名MRPL33、SEPHS2、WDR73，独立报告，不并入主面板确认性结论。单细胞表达差异不用于设定功能效应量；没有使用Locked Test进行设计或新增选择。

**先导阶段：3对新供者。** 每基因3条独立CRISPRi向导；3条非靶向对照、mock、实验室已验证的阳性扰动对照。先校准约40%、70%、90%抑制档位，记录两种组织中实际RNA及蛋白抑制率；名义诱导剂量相同不等于靶点抑制相同。主筛选只使用预先校准的一个档位，渐进抑制和分子质控另计资源。采用CRISPRi是为了减少核酸酶切割造成的[拷贝数相关假依赖](https://pubmed.ncbi.nlm.nih.gov/27260156/)；部分抑制与完全敲除可有不同表型，参见[部分基因抑制研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC10464129/)。向导仍须按实际模型的基因组、TSS及脱靶风险设计，模板中的向导ID不能用于订购。

每供者2次独立培养运行，每次3块96孔板；每板同时放置肿瘤和正常肾的26种条件各1孔，随机分配到内部60孔，边缘36孔作缓冲，内部余8孔预留。总计18块板、936检测孔；三块板是技术重复，两个运行也不是新增供者。纵向活细胞计数在诱导前D0、D7、D14进行，分子抑制质控须覆盖起效阶段及D7；凋亡、增殖和ATP作为辅助终点。若使用破坏性测量，须增加独立时间点板，不能复用上述预算。培养基采用各模型适宜条件，记录培养基与基线增殖，并检查培养基敏感性，避免把培养条件伤害当作选择性。

**分析单位与终点。** 对每条向导定义 `L=-log2[(N处理,D14/N处理,D0)/(N非靶向,D14/N非靶向,D0)]`，正值表示相对细胞积累减少；主差异为同供者 `Δ=L肿瘤-L正常`。技术重复先按预定规则汇总，向导与运行等权汇总到供者；供者数才是n。该终点包含停滞和死亡，不能单凭L声称杀伤。零计数须按检测下限报告为删失，不能任意加伪计数；阳性对照失败、污染、预先定义的成像失败或靶点抑制失败按盲态QC处理，报告全部排除与失败模型。不能根据效应大小排除供者或择优挑向导。

肿瘤与正常模型增殖不同会影响细胞积累终点，因此同时报告基线、非靶向增长、凋亡及[增长率校正指标](https://pmc.ncbi.nlm.nih.gov/articles/PMC4887336/)；对照不增长时不计算GR，也不据常规终点独自声称已纠正增殖差异。正常近端小管身份与功能保留须有模型适用的标记和功能读出，例如LRP2/SLC34A1、摄取功能；“正常细胞数未下降”不能替代完整肾安全性。

**确认阶段及判定规则。** 先导用于决定实验是否可行，不用于确认靶点。4个主基因均保留在确认家族；每基因至少2条独立向导，按靶点抑制和序列质量选定，不能按先导细胞存活表型择优。确认使用新供者，先冻结抑制档位、终点时间、分析与排除规则，再开始收集确认结果。建议的效应阈值是设计假设，须在确认前结合实验可行性明确记录：

| 条件 | 需满足的方向性界限 | 含义 |
|---|---|---|
| 肿瘤功能效应 | 肿瘤L下置信界>1 | 相对非靶向细胞积累至少减少50% |
| 配对差异 | Δ下置信界>0.5 | 肿瘤损伤超出正常肾的预设差异 |
| 正常肾保护 | 正常L上置信界<log2(1/0.8)=0.3219 | 排除超过20%的相对细胞积累损失 |

采用4基因×3界限的保守Bonferroni控制，每个方向性界限α=0.05/12；每基因三条件必须同时成立。至少两条向导方向一致、抑制程度可比，再用独立RNAi或其他正交扰动以及抗扰动等位基因救援复核；[多向导及救援的验证原则](https://pmc.ncbi.nlm.nih.gov/articles/PMC6741428/)用于减少脱靶和克隆伪影。上述界限仅支持特定模型和抑制档位下的实验选择性；正常功能读出受损或增殖校正不支持时降级解释，不能称临床治疗窗。肿瘤与正常均受损应报告为共同/谱系依赖；靶点抑制失败应报告技术不确定；阴性正常检验不等于正常安全。

**样本量没有用表达数据冒充功能方差。** [power_sensitivity.csv](results/historical/functional_validation_design_v1/power_sensitivity.csv)包含36个假设情景，使用非中心t解析计算，无模拟数据。按每基因三项联合检验的失败概率分配，为联合功效下界80%或90%规划各项功效；满足三项的n应取所选三个情景所需n的最大值。它不保证四基因全部通过，也不包括救援/正交复核成功概率。例如Δ均值1、供者差值SD=0.5、零假设界限0.5时需要21个完整配对；正常L均值0.1、SD=0.2、保护界限0.3219时需18对。若同时假定肿瘤L均值1.5、SD=0.5，三项取最大值为21对，假定20%配对模型失败则招募27对。所有均值、SD和失败率都是规划假设，实际确认n暂未固定；3对先导不足以可靠确定方差，应结合更多可行性样本或外部功能数据保守更新并冻结。

可审查产物为[设计配置](configs/functional_validation_design_20261010.json)、[板位模板](results/historical/functional_validation_design_v1/pilot_plate_layout.csv)、[分组解码键](results/historical/functional_validation_design_v1/allocation_key.csv)、[模型库存空表](results/historical/functional_validation_design_v1/model_inventory_blank_template.csv)、[抑制校准空表](results/historical/functional_validation_design_v1/engagement_calibration_blank_template.csv)、[观测空表](results/historical/functional_validation_design_v1/observations_blank_template.csv)与[核验记录](results/historical/functional_validation_design_v1/design_validation.json)。实测字段全部为空，PLACEHOLDER供者不是实际样本。成像分析人员在QC锁定前保持分组盲态，解码键与分析数据分开管理；上传正式模型信息后生成新的冻结版本，不能覆盖当前模板。18块先导板预算不包括校准、分子质控、破坏性辅助读出、正交扰动、救援或确认阶段。

核验命令：`python scripts/verify_functional_validation_design.py`。生成其他版本：`python scripts/prepare_functional_validation_design.py --output-dir results/historical/functional_validation_design_v2`，已有目录拒绝覆盖。下一步先填真实模型库存及平台能力，完成培养、身份、污染和抑制校准，随后冻结实验室适配版本；当前设计尚未进入湿实验执行。

## 最终成果

### 方法层面的结论

1. 表达是当前线性模型预测泛癌选择性依赖的主要信息来源。
2. 表达残差模型相对简单选择性先验的增益在完整癌系留出中稳定，并在独立 Sanger CRISPR 平台上得到有限但方向一致的复现。
3. common-essential 校正是必要步骤；未校正时，较好的 Top-10 指标会被跨模型共享依赖显著影响。
4. 患者迁移可以产生具有一定队列稳定性的候选，但结果对表达域映射明显敏感。
5. 锁定 Test 支持候选频率和部分表达方向的未见队列稳定性，没有提供患者功能准确率。
6. 历史冻结核岭不是最强 baseline；PCR-ridge 和训练内调参核岭在内部和 Sanger 外部均更好。项目贡献应定位为严格评价、跨平台审计和 ccRCC 候选证据整合，而不是新的最优预测算法。

### 候选层面的结论

| 候选 | 已有支持 | 主要冲突或缺口 | 当前合理定位 |
|---|---|---|---|
| PAX8 | CRISPR、RNAi、直接 loss-of-function 文献方向最一致；RNAi 中显示相对其他 Kidney 的负向信号 | 正常肾高表达、正常肾类器官功能风险、肿瘤相对正常低表达 | 最值得做机制与治疗窗实验的候选，尚不是已验证治疗靶点 |
| HNF1B | RNAi 绝对依赖复现，非同行评议直接扰动资料支持 | ccRCC 相对其他 Kidney 区间跨 0；正常肾暴露和类器官风险；Test 表达区间跨 0 | Kidney 谱系机制候选 |
| FERMT2 | RNAi 绝对依赖复现，Test 表达方向复现 | 缺少亚型特异性、直接功能文献和患者来源验证 | Kidney 谱系候选 |
| CCND1 | 直接文献、肿瘤高表达和 tractability 记录；Test 表达方向复现 | DRIVE 绝对依赖区间跨 0，未建立 ccRCC 特异依赖 | 可成药性与表达候选，功能复现不足 |
| YPEL5 | 计算排序入选 | 存在同行评议直接反向证据 | 不宜作为优先抑制靶点 |

GRB2、CFLAR、YRDC 和 CHMP7 目前只有三个冻结 Sanger 肾癌模型一致的细胞系跨平台信号。其余候选仍主要是计算假设，不能把“没有检索到证据”解释为无效。

### 项目最终能够支持的表述

> 本项目建立了一套经过完整癌系留出和外部平台检查的、由表达驱动的选择性依赖优先排序流程，并得到一个保持原始发现顺序的 ccRCC 实验候选集。患者队列结果支持候选稳定性，但不构成患者功能依赖验证。

当前结果**不能**支持以下表述：

- 已发现或证实患者特异的 ccRCC 功能依赖；
- 某个候选已经具有正常肾治疗窗；
- 某个候选已经被证明具有临床疗效或安全性；
- 患者表达排序等同于药物反应或基因敲除结果；
- PAX8、HNF1B、FERMT2 或 CCND1 已经是可直接转化的治疗靶点。

## 现有不足和偏差来源

1. **缺少患者功能真值。** TCGA 只有表达和临床信息，没有对同一患者肿瘤进行候选基因敲除后的生长结果。这是当前最关键且无法通过增加模型复杂度解决的缺口。
2. **患者跨域映射不稳定。** 两种合理表达映射的 Top-10 重叠约为 0.36，说明具体患者候选可能随映射假设改变。
3. **外部平台绝对准确率仍低。** Sanger 上平均增益为正，但真实 Top-10 重叠很低，模型更适合缩小实验范围，不适合直接给出治疗决定。
4. **ccRCC 样本量有限。** DepMap 中明确 ccRCC 只有 12 个，DRIVE 中映射得到 8 个；亚型特异性区间普遍较宽。
5. **正常组织表达不是毒性实验。** HPA 和 GTEx 能提示正常肾暴露，不能估算药物剂量、安全窗或人体不良反应。
6. **细胞系不能完整代表患者肿瘤。** 培养条件、克隆选择、免疫和微环境缺失都会限制外推。
7. **common-essential 注释来自整个 DepMap 发布版。** 它不是每个训练折内部重新估计，因此存在轻微的信息边界问题。
8. **候选文献审查不是系统综述。** 固定关键词可能漏掉摘要中未写出基因或扰动方式的研究，零命中不等于零证据。
9. **原论文复现仍有限。** 已增加同数据逐靶点 Elastic Net、多任务低秩模型与 Exp-DeepDEP 适配版；尚未逐项重现 TCGA-DEPMAP 或 DeepDEP 的原始预处理、训练目标、特征完整度和优化预算。现有结果不能用于宣称全面优于已发表方法。
10. **尚未完成第二台机器 clean-room 重跑。** 哈希、环境和入口校验均已通过，但还不能宣称从原始公开数据到最终结果已经被独立机器完整复现。
11. **Locked Test 不能再用于新模型确认。** Test 已按冻结协议正式访问一次；v2 可以汇总原冻结模型的既有结果，但之后开发的 PCR 或调参核岭即使在 Test 上运行，也只能标为事后探索，不能作为新的前瞻验证。

## 下一步工作

PCR/DeepDEP 比较、PCR患者迁移/单细胞来源扩展、排序不稳定性来源审计，以及GSE178481标签一致队列的来源复核已完成。统一基因参照没有消除患者名单波动；新队列确认正常肾细胞表达暴露，仍未提供患者功能真值。下一步优先把现有候选证据整理为肿瘤模型与正常肾对照的最小功能验证方案，并预先冻结模型后开展真正新增模型/供者的验证。不能沿用已访问的Locked Test作为新模型独立证据，不能依据表达或条件对照重新排列候选。不同基因空间和历史/新PCR候选须分开报告。Elastic Net更小α的完整认证及第二台机器独立重跑仍未完成；新单细胞隔离环境运行不等于第二台机器的clean-room复现。

如果目标是把论文结论从“计算优先排序”提升为“ccRCC 功能靶点”，下一步所需的不是继续训练相似模型，而是新的实验数据：优先在患者来源 ccRCC 类器官或短期原代模型中对 PAX8、HNF1B、FERMT2、CCND1 等候选进行 loss-of-function 验证，并在正常肾类器官中使用相同扰动和可比较终点评估治疗窗。

- PCR不稳定性审计入口：`python scripts/verify_pcr_instability_methods.py`核对计算，`python scripts/run_pcr_instability_audit.py --train`执行GPU审计；已完成结果拒绝覆盖，`--resume`仅复用签名完全一致的完整案例。`python scripts/summarize_pcr_instability_audit.py`生成图表和紧凑快照，`python scripts/verify_pcr_instability_release.py --snapshots-only`可核验版本化子集；完整核验及覆盖差异核查分别使用同名脚本去掉`--snapshots-only`和`python scripts/verify_pcr_instability_coverage.py`。默认核验只打印结果，使用`--report 新路径.json`可保存新记录并拒绝覆盖已有文件。
- 单细胞扩展使用独立环境：在共享现有CUDA PyTorch的venv中安装`requirements-singlecell-extension.txt`，保留原PCR环境。先用`python scripts/prepare_ccrcc_singlecell.py`下载并锁定GEO输入，再运行`python scripts/run_ccrcc_singlecell_extension.py`；用`python scripts/summarize_pcr_singlecell_extension.py --snapshot`生成综合图表及紧凑快照。
- 新队列复核使用同一单细胞环境：`python scripts/prepare_ccrcc_replication.py`锁定公开输入；`python scripts/verify_ccrcc_replication_methods.py`验证计数汇总；`python scripts/run_ccrcc_source_replication.py`执行GPU汇总与冻结模型推断；`python scripts/summarize_ccrcc_source_replication.py`生成图表及快照；`python scripts/audit_ccrcc_replication_coverage.py`补充有效配对与符号覆盖。正式结果与快照均拒绝覆盖。`python scripts/verify_ccrcc_source_replication.py`复核完整产物，`--snapshots-only`只检查版本化子集，`--report 新路径.json`可另存不覆盖的记录。
- 仅核验版本化扩展快照（不读大矩阵、不需要GPU）：`python scripts/verify_pcr_singlecell_release.py --snapshots-only`；完整本机输入、GPU模型和产物核验去掉`--snapshots-only`。独立数值测试在单细胞环境运行`python scripts/verify_pcr_extension_methods.py`。
